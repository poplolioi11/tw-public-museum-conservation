## 重建與驗收

Python 3.10以上標準函式庫可離線核對公開投影及網站。新增輸入先做來源核讀、原值與範圍檢查，再重建；官方原件不放公開儲存庫。

```sh
python3 scripts/build_exports.py --check
python3 scripts/selfcheck.py
python3 scripts/build_site.py --check
```

資料匯出、目前葉節點、缺量註記、搜尋別名、公立分母、私立獨立層、關係與完成語附表須一致。原字典與原值保持，新增分類由受控清冊產生。錯誤候選須在替換公開匯出前被拒絕；同一官方URL換SHA須另覆讀，不自動接受。

目前查核保留所有未被明確extends延伸的葉節點，同館年不同來源可以同時保留P與N。只有確為接續同一待核斷點的新紀錄才延伸舊紀錄；新增另一來源的有限核讀，不以狀態或日期取代原年報待核。

圖形只呈現有界狀態比例與註記，不加總修護量。重繪需安裝requirements-figures.txt並指定可用繁中字型；一般離線檢查不重繪或下載。網站行為以背景headless瀏覽器核對，公開端manifest與下載按實際bytes及SHA讀回；本機與外部狀態分別驗收。

SQLite跨runtime以相同schema、完整表列與完整性核對邏輯；發行檔仍核精確bytes與SHA。原件雜湊只辨識版本，不能代替正文閱讀。來源、附件、ZIP、同提交CI、網站與私人保存成果各自讀回，不以文件完成推定外部狀態。

既有順序一至六沿革、v0.5.0失敗標籤及後續修正保留各版文件與CHANGELOG。全國完整、全年全量、人類二校、館方或專家認證均未宣稱；不作跨館總量或績效排名。
