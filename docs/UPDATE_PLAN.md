下一步先處理既有館所可定位的新材料；累計、平均、計畫與跨年留來源脈絡，不填單年量。未取得年度／館級界線不推算，件、案、項等不互換。研究筆記維持repo草稿；投稿、DOI、通信與新擴張另依使用者安排。

## 重建與驗收

Python 3.10以上標準函式庫可離線核對公開投影及網站。新增輸入先做來源核讀、原值與範圍檢查，再重建；官方原件不放公開儲存庫。

```sh
python3 scripts/build_exports.py --check
python3 scripts/selfcheck.py
python3 scripts/build_site.py --check
```

資料匯出、目前葉節點、缺量註記、搜尋別名、公立分母、私立獨立層、關係與完成語附表須一致。原字典前綴與原值保持，新增分類由受控清冊產生。錯誤候選須在替換公開匯出前被拒絕；同一官方URL換SHA須另覆讀，不自動接受。

圖形只呈現有界狀態比例與註記，不加總修護量。重繪需安裝requirements-figures.txt並指定可用繁中字型；一般離線檢查不重繪或下載。網站行為以背景headless瀏覽器核對，部署後讀回manifest、公立資料、兩新增頁及全部下載的bytes與SHA；本機通過不能代替實站。

SQLite跨runtime以相同schema、完整表列與完整性核對邏輯；發行檔仍核精確bytes與SHA。原件雜湊只辨識版本，不能代替正文閱讀。來源、附件、ZIP、同提交CI、網站與私人Drive成果各自讀回；不以文件完成推定外部狀態。
