## 下一次更新的觸發條件

已有數值但缺索引，先核既有觀測與來源的館別、年份、定位及範圍，不把補索引當新閱讀。來源未定位、適用正文待核、指定段未定位量及完成語仍依上下文，分開保存；只有具名館務正文、新附件、完成清冊、逐年表或原件換版等具體線索，才依實際範圍延伸查核。沒有新線索不反覆搜尋同文，不把缺量推成全年未做或未公開。

新的原件閱讀另記日期與指定範圍，不追溯改成舊版已讀。關係與完成語覆核以固定識別連回原紀錄，原字典、數值及不確定性保留；父句不跨對象移用，算術吻合不證明總子項或不重複物件。新作業詞、量詞或關係名稱先核規則清冊再納入；未知值不自動歸到相似類別。

## 重建與核對

資料匯出與離線一致性檢查使用Python 3.10以上標準函式庫；網站行為與部署另行驗證。

```sh
python3 scripts/build_exports.py --check
python3 scripts/selfcheck.py
python3 scripts/build_site.py --check
```

新候選先完成來源核讀及範圍檢查；格式、數字、關係或附表驗證失敗時，不替換既有主檔與匯出。

```sh
python3 scripts/build_exports.py --candidate-facts /absolute/path/to/reviewed-facts.json
```

輸入不變時跳過寫入。同一官方URL的SHA改變時預設停止，覆讀並記錄變更後才用`--accept-reviewed-source-change`。一般I/O例外有還原處理，但更新器不保證斷電後自動恢復；固定Git版本與附件另留存。

## 原件與SQLite的不同核對

明確授權的原件bytes重抓須指定儲存庫外快取；抓取失敗或換版不自動改寫原值，也不等於零。版本SHA核對不代替指定原頁核讀。

```sh
python3 scripts/check_original_sources.py --cache-dir /absolute/path/to/source-cache --download
```

跨SQLite版本重建核相同schema、所有完整表列與資料庫完整性；邏輯等價不表示binary bytes相同，實際下載附件仍須符合發行manifest的SHA。v0.5.0失敗標籤及v0.5.1修正沿革保留於CHANGELOG，不因本版改寫歷史驗收。
