# 遮蔽數值的人工抽樣核讀

本階段完成的是抽樣與填寫材料的準備。博物館人工核讀為0／50；圖書館既有凍結樣本為0／120。沒有人工一致率、錯誤率、信賴區間或人工雙校完成結果。

## 博物館的固定母體

採用公開基線v0.18.0，commit `0231eb69cddf2cf49047d46810547afaf1280702`。抽樣母體是`facts.observations`中308筆`record_kind=observation`且`numeric_origin=source_reported`的紀錄；1筆程式推算、2筆既有脈絡及私立館獨立試辦不在母體內。

以排序後的觀測識別清單作不放回偽隨機抽樣，共50筆。抽樣參數、完整母體與抽樣清單雜湊、來源版本、重跑程式及資料庫比對鍵由控制者另行凍結保存。讀者只取得獨立題號與官方來源定位，不取得資料庫紀錄識別碼、預期數字或比對鍵。讀者包與控制者包分開保存於私人工作區，不作公開發行附件。

這是已收錄原報紀錄的品質抽查，不是從全國館所抽樣，也不衡量尚未收錄或未定位的資料。抽樣單位是資料紀錄，並非不重複文物、館所或原表物理格；同一來源、頁面或彼此有關係的紀錄可能同時入樣。

v0.19.0製表時發現2題缺唯一原表列鍵。v0.20.0由最初擷取紀錄與當時保存的來源版本，回到高美館2016原報PDF第77頁／印刷第52頁核對，補足2016年度區塊中總號3001與895列；不由紀錄編號後綴或數值猜列序。公開紀錄只補來源定位，原值保持。

讀者包第二版補了這兩題的中性列鍵，原50題、順序、v0.18.0母體及比較鍵不變；舊包保留。50題現均有來源頁碼及找格提示，定位準備的已知兩項缺口已解；這不表示全部題目已完成原件重讀或人工核讀。人工完成仍為0，定位準備不是人工一致率。

## 圖書館的既有固定樣本

沿用圖書館v0.9.1的120筆凍結樣本，不重新選取。固定commit為`4c4e656d94598627c364a49beb967ec437dff037`，母體58,245筆。三層分別為掃描卷369抽60、文字PDF 39,342抽40、結構資料18,534抽20。

本輪更新閱讀入口與識別碼遮蔽，不改樣本或凍結原始空白填寫表。圖書館v0.9.2後增的24筆不在這份v0.9.1樣本內；不得把它稱為新版全部資料已抽核。三層的抽取比例不同，不能直接合併120筆推成全庫錯誤率。

## 讀者填寫方式

1. 依題號開啟官方原件或經來源雜湊核對的私人選頁，確認原檔頁碼、印刷頁、表名與列欄。選頁附件另有自己的頁碼與雜湊。
2. 自行抄錄原字串、原單位、期間與對象範圍，保留支持判讀的欄頭、註腳或段落位置。博物館另填作業詞及完成用語；圖書館使用原凍結的14個人工欄，額外觀察可記在notes。必要找格詞是定位提示，不是資料庫解答。
3. 原格為0、空白、符號、近似值或無法辨識時分別記錄。取得失敗、定位不明與口徑不明也保留同題號，不替換成較容易的樣本。
4. 已看過同格資料庫答案或受到其他提示時記錄可能揭盲。製表AI可接觸資料庫，不能因此稱它是獨立讀者；人工是否未見初值須依實際情況記錄。
5. 完成後另存讀值檔，保留原始空白範本。控制者再與另存的資料庫比較鍵逐欄比對；該鍵是待驗的資料庫內容，不是人工標準答案。

原件本來就包含官方數字，這是核讀所需的證據。遮蔽的是額外呈現的資料庫預期答案；它不能阻止讀者自行查公開資料庫，亦不能單憑檔案檢查認定已完成盲讀。

## 核讀之後

先報完成、無法取得、無法定位及無法判讀的筆數，再分別處理原值、單位、期間與範圍的一致情形；博物館另核作業詞及完成用語。不一致須回到原件裁決，不能立即當成資料庫錯誤；不能判讀也不能算作正確或悄悄自分母刪除。

只有取得實際人工紀錄後才估計一致程度，並按固定母體、抽樣設計與未完成情況說明推論限制。作者本人抽樣核對、另一位讀者的核讀與完整獨立雙校是不同層級。本階段沒有填寫上述結果，也沒有取得DOI或對外送稿。
