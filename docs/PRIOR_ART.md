# 既有成果與本專案的查核界線

一般查核截至2026-10-26；故宮專項於2026-10-28補核，範圍見下方。這是已查官方入口、公開研究與限定搜尋的有界結論；不宣稱窮盡所有網站、附件或未被索引的成果。

本專案不主張全國首次，也不主張過去沒有人整理保存修護資料。現有名錄、單館分項及部分跨館統計均應優先辨識與沿用。

[博物之島](https://museums.moc.gov.tw/)及其年度業務平台相關入口在本輪查核遇維護公告，無法據此判定其全部欄位、匿名下載或歷史涵蓋範圍。另一路文化部名錄OpenAPI可讀，也不能推論維護中的業務平台必定有或沒有修護年序列。

在本輪已查範圍內，尚未核實取得可直接沿用、可區分公立館別與年度、且計數對象為動產文物修護／修復完成量的成熟同範圍整合年序列。這不表示全球沒有相同成果，也不表示中央沒有收集、所有資料均未公開，或搜尋未見的附件不存在。

本專案目前的補充價值在來源版本、頁碼、作業詞、完成狀態、原單位與重疊關係的逐筆索引，並公開已覆讀子集。若後續核得同範圍可用官方或既有整合，應優先引用、比對與補缺，避免重複建置；不能只因換了格式便宣稱原創數據或首次整理。

本版不從審核評論、經費、個人或廠商資訊建立排名與責任分析；前述審計報告僅作既有數值統整及來源定位的證據。

## 2026-10-28故宮專項補核

本輪定位正式年報、永續報告與114年度單位決算業務實績，採用範圍見[NPM](NPM.md)。官方VDR已有四年整合，應直接引用並保留其口徑；2025出版年不是表內資料年。年報及VDR同年原量詞、原數字可不同，不擇一覆寫，也不推差異原因。

有界GitHub／研究查找另識別文物影像、典藏存量與個案研究等不同用途；它們不能直接代入本題年度修護流量。未核得同範圍可直接替代的成熟整合，不表示全球不存在，也不以重做官方四年表宣稱創新。本專案補充逐筆來源版次、原量詞與跨來源不相加關係。
