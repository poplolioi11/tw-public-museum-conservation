# 既有成果與本專案的查核界線

查核截至2026-10-26。這是已查官方入口、公開研究與限定搜尋的有界結論；不宣稱窮盡所有網站、附件或未被索引的成果。

本專案不主張全國首次，也不主張過去沒有人整理保存修護資料。現有名錄、單館分項及部分跨館統計均應優先辨識與沿用。

| 既有來源 | 已知可見範圍 | 與本專案範圍的關係 |
|---|---|---|
| [文化部博物館名錄開放資料](https://data.gov.tw/dataset/6242)及[文化部名錄OpenAPI規格](https://opendata.culture.tw/openData/openApi/emapJsonH) | 館所名錄與基本識別欄位 | 名錄可作盤點基礎；館數或典藏存量不等於文物年度修護流量 |
| [文化部典藏網統計](https://collections.culture.tw/Count) | 各館文物總數、公開及開放資料數 | 屬藏品存量與公開狀態，不可代入修護完成量 |
| [審計部111年度中央政府總決算審核報告：文化部主管](https://auditreport.audit.gov.tw/ServerFile/Get/638258812421990329cbffcff349634e02ad9d657375fceae8) | 表13，PDF序號17／印刷丙571，部分文化部所屬館2018–2022累計待修復、實際修復與年底尚未修復；原單位含件／冊／組 | 已有跨館部分統整；五年累計不能拆成各年，也不是全國館所全量 |
| [故宮2025永續發展目標自願檢視報告官方網址](https://ncsd.ndc.gov.tw/_ofu/VDR/79c878d4-a671-44fd-be76-3fe7526314a8/VDR.pdf) | 官方網址搜尋索引可見2021–2024分材質修護處理及展前狀況檢視表線索 | 本輪未取得可核的原PDF、頁碼與原件SHA，僅保留待核線索，不收其數字為已核觀測；修護與檢視不可混加 |

| [史博文物醫生館](https://exhibitonline.nmh.gov.tw/nmhh2024/page05.aspx) | 單館近年修護成果精選、保存維護與科學檢測介紹 | 個案成果已有公開展示，精選案例不能推為單館或全國年度全量 |

[博物之島](https://museums.moc.gov.tw/)及其年度業務平台相關入口在本輪查核遇維護公告，無法據此判定其全部欄位、匿名下載或歷史涵蓋範圍。另一路文化部名錄OpenAPI可讀，也不能推論維護中的業務平台必定有或沒有修護年序列。

在本輪已查範圍內，尚未核實取得可直接沿用、可區分公立館別與年度、且計數對象為動產文物修護／修復完成量的成熟同範圍整合年序列。這不表示全球沒有相同成果，也不表示中央沒有收集、所有資料均未公開，或搜尋未見的附件不存在。

本專案目前的補充價值在來源版本、頁碼、作業詞、完成狀態、原單位與重疊關係的逐筆索引，並公開已覆讀子集。若後續核得同範圍可用官方或既有整合，應優先引用、比對與補缺，避免重複建置；不能只因換了格式便宣稱原創數據或首次整理。
