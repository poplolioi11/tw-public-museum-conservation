## 先沿用官方既有整合

[官方2025永續發展目標自願檢視報告](https://www.npm.gov.tw/NewFileAtt.ashx?lang=1&id=10058455)已在PDF37／印63列2021–2024四類修護與展前檢視表；PDF46的方法學明示涵蓋這四年，出版年月見PDF49（114年10月）。本專案沿用這份官方整合，不主張首次建立故宮年序列。其他典藏影像、文物資料庫或名錄不等於年度修護流量。

永續表各格原量詞均為件；年報2022–2024原量詞為筆。2021圖書文獻類，年報原列325件，永續表原列342件。兩來源原值、量詞及版次並存，尚未核定差異原因，不宣稱一方正確／錯誤，也不把同年兩筆相加。20組並列關係只協助查找，不證明完全相同物件母體或去重關係。

另核[114年度施政績效報告](https://www.npm.gov.tw/NewFileAtt.ashx?lang=1&id=10059079)PDF25–26指定範圍，未定位本題修護量；包裝改善百分比不反推物件數。這是該來源有限範圍的結果，不覆蓋同年決算已取得的數字，不表示全館零修護或未公開。
