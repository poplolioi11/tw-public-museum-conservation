# 官方統計的公開範圍審查

本頁記錄必要事實投影的納排準則。v0.20.0將經原頁覆核的14則官方環境作業事實另建最小附表；不匯入私人補錄或逐筆審查表，也不混入修護主觀測。另2則暫緩、1則關聯既有紀錄而不新增。採用範圍見[環境作業附表](PRESERVATION_STATISTICS.md)。v0.21.0另採8則一般作業文字，限原文對象、角色與流程，不轉為人數或待修量；見[文字附表](PRESERVATION_TEXTS.md)。經費維持不公開。

## 可審查的資料

| 類別 | 可以考慮保留的必要事實 | 必須分開或暫緩的情況 |
|---|---|---|
| 待修／尚未修復存量 | 官方明列的機構範圍、統計時點、原數字、原單位與定義 | 修前個案描述、特定展品狀態、年度完成量或歷史專案不能代替年末待修存量；跨來源同一個案不重複 |
| 保存修護人力 | 可辨識為保存修護工作的機構層級員額或人數，並保留時點 | 編制、實際在職、請增規劃、約聘、委外、志工及專案分開；不數姓名、照片人頭或表列物件，不推全時當量 |
| 環境控制 | 一般性監測／維護敘述，或有明確原單位與期間的作業次數 | 不公開庫位、平面、安全設備配置、操作細節或可定位的防護缺口；作業次數不證明品質、達標或文物安全 |
| 狀況檢視 | 原報檢視數量、對象與期間，保留抽樣／全量及借展範圍 | 檢視、登錄、拍照混合量不拆為純檢視；不當成修復量、不重複物件數或權屬證明 |

沒有適用數字時只保留有來源的一般性文字，不能補零、依單一作品名補一，或把小組名稱轉成人數。只有截止時點、沒有累計起點的資料，不轉寫成該年新增量。原表合計與分項、父機構與分館、不同文獻中的同一作業，均須先檢查重疊關係。

經費、採購、廠商、個人聯絡資料、責任分析、私人工作紀錄及未核候選不納入本版公開投影。原件全文、頁圖與完整HTML不作公開附件；需要回查時保留官方連結、版本雜湊與必要定位。

## 逐筆採用前的條件

1. 官方來源確實公開，來源版次與SHA可核對，且原頁或指定段落已核實；來源表有同一個ID不能代替正文閱讀。
2. 機構、期間、對象、單位與作業定義足夠清楚；不明項保持未知，不能從出版年或父機構數字推定。
3. 只選本題必要、非個人的事實欄位，移除不必要的人名、地點與設施細節；不把來源中的評價改成整理者的績效判斷。
4. 確認與既有公開觀測的關係。已收錄的同一事實不再次計為新增；僅數字相同不能證明兩筆重複。
5. 權利狀態、第三方內容、公開欄位與封裝各自核對。私人審查表不作公開輸入，另建立可審查的必要事實投影後才可進入發布檢查。

## 授權與利用依據

政府資料開放授權條款只適用於機關依該條款釋出的資料，包含顯名義務；不能因文件在政府網站上就假定整份文件均採相同授權。[政府資料開放授權條款第1版](https://data.gov.tw/license)

智慧財產局說明，單純羅列客觀數量、數據與事實的報表可能不具著作保護要件；仍需區分客觀資訊與具有創作性的文字、編排或圖片。本專案據此採必要事實與短定位的做法，不對整份來源出版品重新授權。[智慧財產局電子郵件1140326](https://www.tipo.gov.tw/tw/copyright/692-33512.html)

已合法公開個資的蒐集與後續利用仍有不同條件，且應符合特定目的與必要範圍。本索引直接排除不必要的個人欄位。[個人資料保護法第5、19、20條](https://law.pdpc.gov.tw/LawContent.aspx?id=FL010627)

上述是本版的來源利用與資料品質邊界，不是對所有候選作成法律認證。機關資料有錯漏時仍須依原件更正；保留來源、疑義與更正紀錄，不能由未定位資料推論機構未執行或未公開。
