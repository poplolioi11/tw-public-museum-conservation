# 既有觀測的30格關聯索引回填

v0.14.0｜2026-10-30

本輪補上已有原報觀測、卻尚無來源查核索引的30個館年格。新增紀錄是連回既有證據的關聯索引，不是新原件閱讀、重新驗數字或新增30份報告。以`review_id`前綴`index-backfill-`可在[查核JSONL](../data/body_reviews.jsonl)查找。

## 核對了什麼

本輪以本機程式核對所有新增索引的組織、目標年、觀測ID、來源ID、PDF頁序／印刷頁及原來源範圍，另以獨立核對程序確認：只補已有單年觀測而未有查核索引的格；連結來源及原觀測內容不變；沒有冒稱新原件閱讀。本30格所連觀測均為PDF來源，不製造HTML定位。

這是對既有證據中繼資料的關聯核對，不能代替重新核讀官方原件，也不能升格為全年全部作業認證。原報數量、完成狀態、對象、單位、原列關係及限制仍以各觀測為準。

## 與其他附表的關係

回填後的467個目前葉節點對應456館年格。同格可同時有數值來源與指定段未定位量來源，全部保留，不取最高狀態。原歷史基線426格與回填前恰為426格的查核集合並非相同母體；本版依[COVERAGE](COVERAGE.md)分開列出歷史基線、已查核集合及聯集。

[ABSENCE](ABSENCE.md)的275則分類針對原有指定段未定位量註記，不因本輪補關聯索引而成為新原報閱讀。分類狀態、館年狀態與觀測數值是不同粒度，不能混用或加成修護物件總量。
