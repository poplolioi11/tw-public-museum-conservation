# 正文補讀與目前查核（v0.12.0）

本版補追原49格待核正文，另利用既存正式原件補核新竹兩館2022年2格，共51個館年格。新增6份官方PDF原件版本及59則延伸查核；同一格可有兩次後續覆讀，所以59不是59個新館年。既有298列紀錄、316來源、450查核及關係的完整字典保持，原名錄與歷史426格矩陣不改。

原49格目前為8格指定段未定位適用量、1格年度不可拆、40格仍待適用正文。另2格新竹2022年均為指定段未定位適用量。本輪沒有新增合格數值；讀到課程、展覽、藏品存量、父機構業務或跨年歷程，不能轉成指定館年的保存修護量。

## 如何讀目前與歷史

每則查核保留review_id；extends_review_id只指向同一候選識別及目標年的先前紀錄。被延伸的原紀錄仍在主檔、CSV、JSONL與SQLite中。所謂「目前」是尚未被任何後續查核延伸的所有紀錄；同館同年有多個獨立來源或範圍時全部保留，不以日期或狀態好壞選一筆。更新器會拒絕循環、自我延伸及跨館年連結。

全版509則含歷史，目前437則對應426組候選識別×目標年；這與原71組織的426格歷史索引矩陣不是同一集合。metadata/read_coverage.json另列目前review_id與六狀態數量，仍不是全國公開率或全年作業完整率。

來源頁段分別保留text_read_pdf_pages_1_based、image_viewed_pdf_pages_1_based及verification_status；未列時不補推。HTML也可能是實際正文，PDF也可能僅為目次或會計表，檔案格式不代表核讀深度。頁碼為PDF序，印刷頁與HTML定位另列。

## 原口徑與後續

成大2025出版專刊敘述較早的修復歷程，不依出版年回填2025量；配件構成也不是當年作業量。梅嶺指定段列跨年持續辦理，沒有可採物件量，不把計畫名稱點算成案數或已完成件數。馬祖年鑑的「近年」整理、藏品存量與教學實作不代2024年度處理量。新竹已存影像原件另實看館務工作列，未將局級合列工作拆配各館。花蓮父局規劃仍不能代館級動產保存正文。

6份新採用原件共129,140,589 bytes，保存副本與直接雲端原始檔讀回大小及SHA相符；完整官方PDF、圖文與工作中間檔不重新散布。公開仍為必要事實、原詞與定位，原件權利不因本專案MIT改變。來源取得、指定正文讀核、資料匯出、網站互動及正式部署各自驗收。

網站的解讀標籤不覆寫metric_as_reported；例如4冊是專案辦理對象、未明載完成，不能當全館全年已完成總量。下載CSV同時提供metric_label與原詞。既有完成分類、跨年不拆、雙單位及不相加關係繼續保留，不為全部舊紀錄猜配新的量值角色。

40格待核優先依具體新官方附件或既存未讀原件續查；同型取得失敗先保留缺口。未定位不是零，也不推機關未做或未公開。
