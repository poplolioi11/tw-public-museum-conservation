# 40格原件補讀與缺口（v0.13.0）

先核已保存原件及未讀頁段，再依新官方線索補取原件。40格均有本輪有界跟進，不代表40份館務正文全部取得或已全文核讀。新增採用3份既存PDF與3份新官方PDF，共6版本；新增43則延伸查核，包含3則接續本輪先前紀錄。原298列、322來源、509查核及關係完整字典保留。

原40格目前1格已核原報數值、3格指定段未定位適用量、36格適用正文待核。未知不是零，不表示館方全年未辦理或未公開。

## 新增數值及其限制

有章藝術博物館：111年6月7日校務會議原報PDF42／印42，「四、典藏業務辦理」之「（三）典藏品修復」列海報6件。原文稱為展示及保存需求而修復，沒有另載「完成」；依本學期業務報告分項保留，不推2022全年完成總量。捐贈者姓名、提借件數、典藏審議存量、展覽或外部服務項目不作本筆處理量。可沿主檔source_id及官方原件頁碼回查。

臺藝大110學年度第1、2次會議實際日期分別為2021年12月28日與2022年6月7日；114學年度第1次會議為2025年12月16日。學年度與曆年分開，不按檔名回填資料年。2021、2025具名博物館指定段未定位可採處理量，仍不推全年無量。

花蓮2021具名考古博物館營運章在跨期報告PDF64–65／印426–427，報告期段為2021年9月1日至2022年3月31日；指定段為營運、展覽與教育推廣及典藏研究職掌，未列適用保存修護處理量。另一份2020–2021跨期檔仍未定位適用館級動產保存正文，保留待核。

南投2025文化統計年報以2025年為主要資料年，封面出版日期2026年8月18日另列；館舍圖片與全縣藝文活動分類表不拆配竹藝館修護量。苗栗2021現存20頁為會計報表節錄，補核剩餘頁頭與文種不等於取得兩館年度保存正文。
