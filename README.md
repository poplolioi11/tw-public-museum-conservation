# 臺灣公立館保存修護公開資料索引（持續整理）

這個專案將分散在官方年報、年度成果與統計表中的保存修護資料整理成可回查的索引。重點是讓讀者知道數字出自哪一版、哪一頁、指什麼對象，以及哪些數字仍不能比較。

目前試行版本為 **v0.4.0**，資料截至 2026-10-26；發行日期為 2026-10-26。儲存庫名稱為 `tw-public-museum-conservation`。

原名單PDF尚未取得可供正文核對的版本，基線仍保留「僅索引轉錄」層級。來源查找格的索引、正文與數值核讀層級也分開記錄。補充候選與部分館的續核，不會使整張基線來源矩陣自動升級為已核數值資料。

公立、公設民營、設置機關、權管機關與營運單位分別處理；行政或場址關係不代表每件藏品所有權。這份索引不作企業分析，也不主張涵蓋全國全部館所。

本版191列分為 **188筆原報觀測、1筆程式推算、2筆脈絡分項**；其中3筆為未拆年的跨年整飭量。數值涵蓋15個館所／管理中心，連同來源查核共18個單位。98份來源含96份PDF與2份官方HTML；不同用途及館所年度不能相加當修復量。

## 如何閱讀

先看館名、資料年與原報作業詞，再看單位、對象範圍和完成狀態，最後回官方網址與頁碼查核。資料年與出版年分欄保留；報告標稱年另見來源標題，不能互相代換。

- 原報明載值保留原數字字串與原單位；程式推算值另標計算關係與依據，不能冒充原報總述。
- 件、冊、組、組件、案、條、號、項、套、頁與次不可混加；同為「件」也要先核計數對象。
- 修復、修護、整飭、清潔、巡檢、科學檢測與數位化不是同一指標。複合計畫未拆分時保留複合範圍，不改稱修復總數。
- 已完成、進行中、預計完成及待修分開；進行量不能加到完成量。
- 總項與子項、母館與子館、同一計畫不同報告或可能重疊批次，沒有明確包含與去重證據便不相加。
- `unknown`、`null`、原刊留白及未定位來源各有含義。未知不是零；只有來源明載且語義確認的零才能記為零。

本版可用於查找官方來源、檢查口徑與辨識缺口。它尚不是全國修護完成總量、同質工作量或可比較的績效排名。即使同館連年用相同作業詞，也不代表處置難度、工時或不重複物件規則一致。

## 公開的是什麼

公開內容採白名單事實投影：館所識別、來源網址、版本、必要原詞與數字、單位、資料期間、頁碼或表格位置、短定位詞、核讀狀態及本專案的中性說明。逐筆資料以本版發行檔案清單為準。

官方PDF、整頁文字、頁面圖片與完整網頁不隨本版重新發布。私人儲存路徑、雲端工作區識別、個人與廠商聯絡資料、工具紀錄及完整中間檔也不在公開範圍。

`original_file_sha256`記錄取得的官方原件內容；公開投影的SHA另列。公開投影不是原件，兩者的bytes與雜湊不應被當成相同。只讀到搜尋索引而未取得原件時，原件SHA及頁碼維持未知，不使用索引快照雜湊冒充。

## 本批新增與限制

補臺史博2022–2024藏品修護表，每年保留緊急加固、日常維護、完整修護及原報合計。2023緊急加固的0為原表明列，僅代表該分類；同年日常維護採件數欄11，項目欄另列13件的範圍關係未核，保留註記，不改表值或另建數量列。原表「實體件數」不等於本專案已核跨作業唯一物件。

大溪木博2021為檢視登錄、清潔、攝影及保存評估等複合整飭量；2025「463組（715件）」保留整個原字串，精確數值欄null，不拆成兩筆獨立工作量或當純修復。其他指定章段未定位數量，不代表全年沒有作業。

十三行新增燻蒸活動次數與館藏陶缽修復分項；借展品另列，方向與權屬未推定。2022既有觀測只連回，不新增重複。未核清對象邊界的修整分項不進公開數值。

高史博2024原報5案、24件、22項工作；2025原報4案、355件、2項計畫。各列保留原單位與作業詞，未建立件、案、項換算或包含關係；維護修復合報不改稱純修復。未核出版年者保留null。

原v0.3.0的164列證據與查詢標籤含義保留；分類規則版本更新為1.1，以承接同型年度表與完成狀態文字。新增「資料樣貌」及中文補充正文查核狀態，0則補充紀錄不代表已有數值未查來源。互動查詢網站尚未部署。
