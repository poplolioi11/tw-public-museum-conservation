# 臺灣公立館保存修護公開資料索引（持續整理）

這個專案將分散在官方年報、年度成果與統計表中的保存修護資料整理成可回查的索引。重點是讓讀者知道數字出自哪一版、哪一頁、指什麼對象，以及哪些數字仍不能比較。

首次試行版本為 **v0.1.0**，資料截至 2026-10-26；發行日期為 2026-10-26。儲存庫名稱為 `tw-public-museum-conservation`。

## 如何閱讀

先看館名、資料年與原報作業詞，再看單位、對象範圍和完成狀態，最後回官方網址與頁碼查核。資料年與出版年分欄保留；報告標稱年另見來源標題，不能互相代換。

- 原報明載值保留原數字字串與原單位；程式推算值另標計算關係與依據，不能冒充原報總述。
- 件、冊、組、組件、案、條、號、項、套、頁與次不可混加；同為「件」也要先核計數對象。
- 修復、修護、整飭、清潔、巡檢、科學檢測與數位化不是同一指標。複合計畫未拆分時保留複合範圍，不改稱修復總數。
- 已完成、進行中、預計完成及待修分開；進行量不能加到完成量。
- 總項與子項、母館與子館、同一計畫不同報告或可能重疊批次，沒有明確包含與去重證據便不相加。
- `unknown`、`null`、原刊留白及未定位來源各有含義。未知不是零；只有來源明載且語義確認的零才能記為零。

本版可用於查找官方來源、檢查口徑與辨識缺口。它尚不是全國修護完成總量、同質工作量或可比較的績效排名。即使同館連年用相同作業詞，也不代表處置難度、工時或不重複物件規則一致。

## 公開的是什麼

公開內容採白名單事實投影：館所識別、來源網址、版本、必要原詞與數字、單位、資料期間、頁碼或表格位置、短定位詞、核讀狀態及本專案的中性說明。逐筆資料以本版發行檔案清單為準。

官方PDF、整頁文字、頁面圖片與完整網頁不隨本版重新發布。私人儲存路徑、雲端工作區識別、個人與廠商聯絡資料、工具紀錄及完整中間檔也不在公開範圍。

`original_file_sha256`記錄取得的官方原件內容；公開投影的SHA另列。公開投影不是原件，兩者的bytes與雜湊不應被當成相同。只讀到搜尋索引而未取得原件時，原件SHA及頁碼維持未知，不使用索引快照雜湊冒充。
