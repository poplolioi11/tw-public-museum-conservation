# 臺灣公立館保存修護公開資料索引（持續整理）

這個專案將分散在官方年報、年度成果與統計表中的保存修護資料整理成可回查的索引。每筆保留數字出自哪個版本、哪個位置、指什麼對象，以及尚不能比較或相加的原因。

本版為 **v0.12.0**，資料截點為 **2026-10-29**，主檔結構版本為 **4.0**。儲存庫名稱為 `tw-public-museum-conservation`。[互動查詢入口](https://poplolioi11.github.io/tw-public-museum-conservation/)提供資料查找；網站與發行版本的驗證，以公開網址讀回及雜湊核對紀錄為準。

數值子集涵蓋25個館所／管理中心；連同來源查核，依`organization_id`涵蓋79個候選識別、80個原報名稱。差異來自同一識別下特生中心與生多所的年度更名，不能當兩間新館。其中5筆跨年紀錄只存一次，未拆年。原71組織的426格歷史來源矩陣，與509則歷史／437則目前查核對應的426組實際館所年度不是同一集合，不因筆數相同而互相替代。原名單PDF仍未取得可供正文核對的版本，基線保留「僅索引轉錄」層級。

公立、公設民營、設置機關、權管機關與營運單位分別處理；行政或場址關係不代表每件藏品所有權。本索引不作企業分析，也不主張涵蓋全國全部館所。

## 如何閱讀

先看館名、資料年與原報作業詞，再看單位、對象範圍和完成狀態，最後回官方網址與定位查核。資料年與出版年分開；報告標稱年另見來源標題。

- `quantity_raw`保留原字串；例如「兩」仍保留「兩」，明確單字數詞由本機程式精確轉為`quantity_numeric=2`。近似量、雙單位合列不猜成確數。
- 件、幅、冊、組、組件、案、條、號、項、頁與次不可混加；同為「件」也須核對計數對象。
- 修復、修護、整飭、清潔、巡檢、科學檢測與數位化不是同一指標。複合作業保留原範圍，不改稱純修復。
- 完成、父項完成脈絡、年度執行、進行中與計畫目標分開；未另載完成日期也不能逕判未完成。
- 總項與子項、母館與子館、不同報告或可能重疊批次，沒有包含與去重證據便不相加。
- PDF保留頁序與印刷頁；HTML兩種頁碼均為`null`，以必填的`source_locator`回到明確年度段落。HTML渲染所得PDF不是官方原件PDF。
- 未知、`null`、原刊留白與未定位來源不等於零。只有來源明載且語義確認的零才記零。

本版可用於查找官方來源、檢查口徑與辨識缺口；尚不是全國修護完成總量、同質工作量或可比較的績效排名。

## 本版新增與限制

本版補追原49格「找到來源、適用正文待核」，並利用既存正式原件補核新竹2022年的2格。新增6個PDF來源、59則延伸查核，原298列數值／推算／脈絡紀錄完整保留，沒有新增合格數字。原49格目前為8格指定段未定位適用量、1格年度不可拆、40格仍待適用正文；不把找到索引或父機構章節當館別正文已讀。詳見[正文補讀與目前查核](docs/BODY_FOLLOWUP.md)。

來源查核預設顯示尚未被後續紀錄延伸的全部紀錄，可依六種狀態查找並顯示歷史。這不是每館年只留一筆、只取較新日期或挑較好狀態。文字已讀頁、實看圖頁與來源原驗證標記分列；目前437則對應426組館年，不能把437稱為437個館年或完整報告。

網站列表與詳情優先顯示已核的解讀標籤，原報作業詞仍保留。蘭陽2025年4冊是原列保存修護專案對象，未明載完成；海科館「整理」也不改稱純修復。跨年、不同單位或可能重疊的批次不相加。原順序一至六的第一輪有界來源查找見[故宮](docs/NPM.md)、[順序二](docs/BATCH2.md)、[順序三](docs/BATCH3.md)、[順序四](docs/BATCH4.md)、[順序五](docs/BATCH5.md)、[順序六](docs/BATCH6.md)。原名錄及426格歷史矩陣不改；後續依新附件、館別正文或完成清冊等具體線索續核。

網站沿用圖書館參考版本commit `558c16b3db18675b6afbaeeb6568af7881d56060`的主檔、帶雜湊JSON、靜態前端與檢查後部署流程；每版本站部署及下載檔仍需公開讀回驗證。

## 公開範圍、查核與引用

公開白名單事實投影包含館所識別、官方網址、版本、必要原詞與數字、單位、期間、來源定位、核讀狀態及中性說明。官方PDF、完整HTML、整頁文字與圖片不重新發布；私人路徑、聯絡資料、工具紀錄及完整中間檔也不在公開範圍。

`original_file_sha256`指取得的官方PDF或HTML原始bytes；公開投影與網站建置SHA另列，不能互相冒充。只讀到索引而未取得原件時，不使用索引快照雜湊冒充原件SHA。
